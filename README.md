# Atharva Rajoba Data Analyst Portfolio

Premium interactive portfolio built with Next.js App Router, Tailwind CSS, Framer Motion, Recharts, and Lucide React.

## Folder Structure

```text
.
├── README.md
├── next-env.d.ts
├── next.config.ts
├── package.json
├── postcss.config.mjs
├── tsconfig.json
└── src
    ├── app
    │   ├── globals.css
    │   ├── layout.tsx
    │   └── page.tsx
    └── components
        └── portfolio.tsx
```

## Local Development

```bash
npm install
npm run dev
```

## Vercel Deployment

1. `npm install`
2. `npm run dev`
3. Push to GitHub
4. Deploy on Vercel
